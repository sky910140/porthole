# 三分钟真实演示脚本

状态：待录制。只有公网入口、OAuth 和 ChatGPT 账号实际可用时才能录制；本机自动化回放不能替代这段演示。

1. **0:00–0:30 安装与选择项目。** 在干净 Windows 11 上安装候选运行包与 VSIX，打开测试项目。运行三步向导，明确展示项目路径、默认只读和分享范围。
2. **0:30–1:00 连接与真实读取。** 配置本人 HTTPS MCP 与 OAuth，在 ChatGPT 发起 `verify_connection`，读取测试项目的 README，展示带路径的结果。
3. **1:00–1:40 提出修改。** 将项目改为“允许提出修改”，让网页调用 `propose_changes`。展示返回的修改编号和 `pending_review`；同时打开文件证明磁盘未改。
4. **1:40–2:20 本机审阅应用。** 在 VS Code 根据编号打开差异，检查目标项目和文件数，明确点击应用。展示页面“已应用，但尚未运行测试”和 VS Code 文件变化。
5. **2:20–2:45 网页查询。** 在原 ChatGPT 对话中调用 `get_change_status`，确认与本机相同的修改编号和 `applied` 状态。
6. **2:45–3:00 撤销。** 在 VS Code 明确执行撤销，再查询状态为 `reverted`，核对原文件内容。

录制时保留时间戳、应用版本、VS Code 版本与测试项目提交号；遮盖账号、令牌和绝对路径中的个人信息。若任一步失败，记录错误码和下一步，不剪辑成成功结果。
