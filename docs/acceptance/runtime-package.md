## 稳定性验证

- 两个并发启动进程复用同一受管理实例；端口冲突路径不终止其他进程。
- 损坏归档、错误架构、不兼容协议和非受信来源均在替换前拒绝，原安装保持不变。
- 离线首次安装给出明确错误；手动服务必须显式选择。
- 五分钟三次异常退出会暂停自动拉起；网络断连只重连，不触发服务重启；手动继续会清空暂停计数。
- 关闭窗口后服务继续供其他窗口使用，并禁止该窗口再启动本机操作。

当前机器已证明运行包不依赖开发运行时。全新 Windows 虚拟机人工安装仍是候选发布门禁；公共下载源、代码签名证书和发布 URL 尚未确定，因此本任务没有启用真实在线下载。
