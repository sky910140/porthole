# 0.7.0 自动连接向导本机验收

日期：2026-10-02—2026-10-03。环境：Windows 11 x64、Python 3.12.14、Node 24、VS Code 1.138.0。已完成本轮实现及本机自测，产出未公开发布的候选安装包。

## 本轮改动

- 官方隧道客户端 v0.0.15 原始归档随 VSIX 提供，安装前校验固定 SHA-256。首次使用不需要从 GitHub 下载，缺失或损坏的附带包不会绕过校验。
- 连接信息、自动检查、ChatGPT 添加步骤、限时验证放在同一页面。保留 Tunnel ID 草稿，关闭后可继续；API Key 仅保存在 VS Code SecretStorage，提交后清空输入，不回填页面。
- 本机自检实际执行 MCP initialize、工具发现和项目列表调用。控制面必须近期成功才显示隧道连通；本机检查不会冒充 ChatGPT 的真实工具调用。
- 区分密钥、权限、Tunnel ID、网络、本机服务和进程故障。运行中的客户端断网自行重连；配置错误暂停恢复，进程连续崩溃限制重启次数。手动停止后不自动拉起。
- 已有项目授权和公网连接配置保留，私有切换失败恢复原配置。更新中英文说明、新手指南、排查表和构建流程；CI 增加向导浏览器检查。

## 尚需外部验收

本轮没有可用的 OpenAI 运行密钥，因此没有完成真实 Platform 控制面认证及 ChatGPT 网页工具调用。本机测试控制面、模拟回执或历史截图均不能替代这个闭环。

全新 Windows 虚拟机安装/卸载、24 小时运行、其他 Python / VS Code 组合以及 GitHub 远端 CI 仍待验证。当前私有隧道需要保持 VS Code 开启，独立后台助手未实现。

首次创建 Tunnel、运行 API Key、账号权限及 ChatGPT 添加应用仍由本人或管理员完成；本轮减少本机配置步骤，不自动创建账号资源。
