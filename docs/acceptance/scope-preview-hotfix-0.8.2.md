# 0.8.2 文件预览修复验收

日期：2026-10-06。状态：本机候选自测通过，未公开发布，未签名。

## 问题与修复

用户在 0.8.1 点击“预览可访问文件”后，只看到“可访问文件 8 个，已排除 6 项”。扫描已完成，但核心接口只返回统计，扩展没有文件清单展示，因此再次点击没有可见反馈。

0.8.2 在原 `/api/projects/{project_id}/scope` 和 MCP `preview_scope` 响应中增加 `files` 与 `files_truncated`。清单最多 200 项，每项包含项目内相对路径、大小及读取方式；不返回文件内容、绝对路径或被排除的路径。总计仍统计扫描范围内全部文件，保留 10,000 项扫描上限。无法访问的目录不会标为扫描完整。

首页项目区新增可折叠清单，点击时直接展开，显示扫描进度、文件明细、排除原因、空结果和截断说明。扫描失败可重新预览；切换项目不会展示其他项目清单，暂停或移除授权会清除缓存，暂停项目拒绝新的预览。文件名通过 `textContent` 显示。旧核心只返回统计时明确提示升级附带版本。
