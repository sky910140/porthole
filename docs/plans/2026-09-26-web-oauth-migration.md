# 0.3.1 网页连接迁移实施计划

目标：从旧配置导入网页 OAuth 连接到 VS Code 管理的本机服务，保留新安装的项目与令牌；整个操作在 VS Code 内完成。

1. 测试先行：覆盖旧配置预检、OAuth 密文校验、目标冲突、成功导入及失败回滚；验证服务身份检查和凭据注入。
2. 实现迁移核心：仅导入旧 OAuth 状态与公网/GitHub 设置，不复制旧项目或本机管理令牌。选择旧配置、输入原 GitHub OAuth App 凭据，在切换前确认 HTTPS 来源和密钥匹配。
3. 接入 VS Code 首页：显示迁移入口、进度和真实网页验证提示。敏感信息只存 VS Code SecretStorage，启动子进程时通过环境变量传递。
4. 启动与升级：只停止精确匹配配置的旧托管实例；校验端口归属，安装新运行包并重启。失败时恢复配置与 OAuth 状态并重启原模式。
5. 验证：单测、核心测试、扩展集成测试、打包与隔离安装；真实 ChatGPT 账户的最终工具调用需要用户在网页完成，不能由本地自测代替。
