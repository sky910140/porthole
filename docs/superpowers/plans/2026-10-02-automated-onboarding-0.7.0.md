# 0.7.0：首次连接与恢复

用户已确认实施。推荐路径为 Windows x64 VS Code 扩展 + 官方私有 MCP Tunnel。

## 交付范围

1. 发布包附带固定版本、SHA-256 校验的官方隧道客户端和许可证；首次安装无需访问 GitHub。
2. 用持续保留进度的单页向导代替连续输入弹窗。Tunnel ID 可保存草稿；密钥仅保存在 SecretStorage，页面不回填密钥。
3. 自动检查本机 MCP 协议、项目授权和隧道控制面。检查结果不能冒充来自 ChatGPT 的真实验证。
4. 在同一页面提供 ChatGPT 添加步骤、复制 ID 和验证提示词；自动轮询验证结果，关闭后可继续。
5. 区分凭据、权限、标识、网络、本机服务和进程故障。网络断开交由运行中的官方客户端重连；配置错误不无限重启；进程崩溃有限重启。
6. 保留原公网连接及项目授权，切换失败回滚。后台独立助手及自动创建 Platform 账号资源另行迭代。

## 验收

- 固定官方归档真实下载并核验；离线从 VSIX 安装隧道客户端；损坏归档不得安装。
- 本机真实 MCP initialize / tools/list / list_projects 成功，但不计为网页验证。
- 401、403、404、网络中断、进程退出分类与恢复行为测试。
- 向导草稿恢复、密钥不回填、重复提交防护、失败可重试、轮询自动完成的浏览器测试。
- Python、扩展单元测试、隔离 Extension Host、打包后 VSIX 安装自测。
- 无运行密钥时，不声称已完成真实 OpenAI/ChatGPT 账号端到端验证。
