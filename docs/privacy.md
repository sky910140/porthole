# 数据与隐私说明

Porthole 在用户电脑运行服务，不会自行把整个项目上传到模型。网页助手只有调用已授权的 MCP 工具时，才会收到对应项目中该次工具返回的文件片段、Git 信息或用户单独允许分享的编辑器上下文；这些结果随后由所使用的网页 AI 服务处理，其隐私条款由该服务决定。

项目默认只读。未保存的编辑器缓冲区默认不分享，必须逐项目开启。修改建议先保存在本机加密内容存储中；远程工具不能直接应用。管理令牌与 MCP 凭据分开，本机长期令牌存于工具状态目录或 VS Code SecretStorage，不应复制到网页对话。

工具不启用自动遥测。结构化诊断只记录受限的事件类型、编号、错误码、耗时和分层连接状态；用户主动导出前可预览，默认不包含项目绝对路径、源文件内容、令牌、OAuth 返回或身份信息。显式选择包含路径时，请先检查导出包再分享。

用户可以在本机撤销项目授权、暂停项目或停止服务。卸载与清理状态数据应按 [发布与升级说明](releasing.md) 检查范围；用户项目源码不属于工具状态目录。
