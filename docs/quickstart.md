# 三步开始使用 AI Zhagan

适用范围：Windows 11 x64、VS Code Stable、本地文件夹。当前提供 0.3.0 本地候选 VSIX，尚未公开发布。

## 1. 安装并打开首页

在 VS Code“扩展”页面点击 `…` →“从 VSIX 安装”，选择 `extensions/vscode/ai-zhagan-context-0.3.0.vsix`。重新加载后按 `Ctrl+Shift+P`，运行 `AI Zhagan: 打开首页`。点击“安装本机服务”；运行包已包含在 VSIX 中，不需打开终端或安装 Python、Node。

## 2. 选择项目

在首页点击“选择文件夹”，使用系统目录选择器选中要共享的本机项目。确认完整目录路径后点击“授权此目录”。新项目默认只允许读取符合排除规则的**已保存**文件。首页显示项目目录、项目标识、访问模式；点击“预览可访问文件”可查看文件数量和排除统计。扫描达到上限时会明确标明“未扫描完整”。

选择其他目录会登记一个新项目，不会把旧项目的修改授权迁移过去。已授权项目可在首页切换、暂停访问或移除授权。选择未打开的目录时，扩展会把它加入当前 VS Code 工作区，以便后续审阅修改。浏览器里的高级管理页仍支持输入绝对路径，但日常操作无需使用它。

## 3. 连接并提问

本机就绪后，首页会分别显示“本机服务”“公网通道”“账号授权”“真实工具调用”。只有最后一层经过 ChatGPT 实际调用，网页连接才算验证成功。

如果 ChatGPT 中已经连接了 AI Zhagan，先询问：

```text
请使用 AI Zhagan 调用 list_projects，参数为 {}。只返回工具实际结果。
```

然后在首页点击“复制提问模板”，将包含真实项目标识的提示词发到 ChatGPT。

首次添加 ChatGPT 网页连接仍需固定 HTTPS MCP 地址、GitHub OAuth 应用、允许登录的 GitHub 数字用户 ID，以及账号侧支持添加 MCP 连接。首页“网页连接说明”会打开扩展说明；准备好这些前提后，可复制验证提示词，通过 `verify_connection` 完成真实调用。**本机安装成功不等于网页已连接。** 自托管步骤见 [README](../README.md#以后连接官方网页)。

网页提出的修改先是待审阅建议。需要时在首页分别点击“允许提出修改”和“允许本机应用”，然后在 VS Code 查看差异并明确应用；网页不能直接改本机文件。
