# 三步开始使用 AI Zhagan

适用范围：Windows 11 x64、VS Code Stable、本地文件夹。首次公开版采用自托管连接。

## 开始前

本机读取可离线运行。要从 ChatGPT 网页调用本机项目，还需要：

- 一个固定的 HTTPS MCP 地址；
- GitHub OAuth 应用和正确的回调地址；
- 配置允许登录的 GitHub 数字用户 ID；
- 账号侧支持添加 MCP 连接。

这些是外部接入前提，向导不会自动登录网页，也不会把令牌写入工作区。

## 1. 选择项目

在 VS Code 打开本地文件夹，运行 `AI Zhagan: 开始或继续三步向导`。多根工作区会要求明确选择一个文件夹，不根据当前编辑器猜测。

运行包缺失时，向导会显示实际安装位置。开发环境可按 [运行包说明](runtime.md) 构建并安装到 `%LOCALAPPDATA%\AI Zhagan\runtime\current`。

## 2. 连接

向导启动同用户的本机服务，用一次性配对码交换凭据，并把长期令牌存入 VS Code SecretStorage。新项目默认仅查看已保存代码。

如需让 AI 看到未保存内容、选区或诊断，在本机管理页为该项目单独开启“共享未保存内容”。

## 3. 试着问一个问题

向导提供四个动作：复制 MCP 地址、打开 ChatGPT、复制验证提示词、查看连接详情。把 MCP 地址添加到网页连接后，在对话中粘贴验证提示词。只有网页实际调用 `verify_connection` 并读取项目成功，诊断才显示“真实工具调用：正常”。

验证后可使用：

```text
请使用 AI Zhagan 读取项目 <项目标识> 中的 README.md，先说明它的用途，再列出依据的文件路径。
```

取消向导不会丢失已完成步骤。重新运行同一命令会从项目、连接或试着提问的相应步骤继续。

## 离线了解界面

本机管理页的“查看离线演示”只展示固定的 `demo-notes` 示例，并始终标注“演示数据，尚未连接 ChatGPT”。它不会扫描本机文件，也不会伪造连接成功。
