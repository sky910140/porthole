# 舷窗 Porthole 快速开始

需要逐项填写说明、成功状态和常见问题时，先看 [初学者操作手册](beginner-manual.md)。

适用：Windows x64、VS Code、本机文件夹。安装包附带本机服务和官方隧道程序，日常使用不需要 PowerShell、Python、Node 或 GitHub OAuth App。

## 1. 安装、打开首页

在 VS Code 的“扩展”页点击 `… → 从 VSIX 安装`，选择 `porthole-0.9.0.vsix`，按提示重新加载。

按 `Ctrl+Shift+P`，运行 `舷窗: 打开首页`，点击“安装本机服务”。已有授权和连接配置会保留；升级过程会生成备份。

## 2. 选一个文件夹

点击“选择文件夹”，在系统窗口选择要让 AI 读取的目录。检查完整路径，确认授权。首次默认只读已保存文件。

点击“预览可访问文件”，项目区会展开“可访问文件清单与排除原因”，列出相对路径、大小及读取方式。扫描时显示进度，失败后可重新预览；文件超过 200 个时只展示部分清单并明确提示，统计仍以本次扫描为准。可重命名显示名、切换项目、暂停或移除授权。选择新目录不会继承旧目录的修改权限。

## 3. 打开连接向导

首页点击“连接 ChatGPT（推荐）”。以后点击“管理连接 / 继续设置”回到同一页面。打开外部设置页面、关闭向导再返回，都能继续填写 Tunnel ID；密钥不会回显。

首次需要准备两项：

| 要填的内容 | 在哪里取得 |
|---|---|
| Tunnel ID | 点击“创建 / 查看 Tunnel”，在 [Platform Tunnels](https://platform.openai.com/settings/organization/tunnels) 创建；复制 `tunnel_` 开头的完整 ID |
| 运行 API Key | 点击“创建运行密钥”，在 [Platform API Keys](https://platform.openai.com/api-keys) 创建具有 **Tunnels Read + Use** 权限的密钥 |

创建 Tunnel 需要 **Read + Manage**，并把 Tunnel 关联到要使用的 ChatGPT 工作区。这些账号权限和关联需要本人或管理员完成；扩展不能代为开通。[官方说明](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)

粘贴两项后，点击“保存并自动检查”。程序从安装包中校验并安装，自动检查本机 MCP、项目授权和隧道连接。已保存密钥可留空继续使用；填新密钥则替换，密钥只存于 VS Code 凭据库。

检查失败时照页面提示处理：

| 提示 | 操作 |
|---|---|
| 运行密钥无效或失效 | 在向导重新填有效的 API Key，保存重试 |
| 隧道访问被拒绝 | 核对所属组织和 **Tunnels Read + Use** 权限 |
| ID 不存在或不可见 | 核对 Tunnel ID 和所属组织 |
| 网络暂时不可用 | 检查网络或代理；运行中的客户端会自动重连 |

## 4. 在 ChatGPT 添加一次并验证

本机检查通过后，向导会显示具体步骤和当前 Tunnel ID：

1. 点击“复制 Tunnel ID”，再点击“打开 ChatGPT 插件页”。选择 `添加 → 创建 MCP 应用`。
2. 名称填 **Porthole**；连接方式选 **隧道（Tunnel）**，填写 ID；身份验证选 **无**。创建并连接应用。
3. 新建 ChatGPT 对话，选中这个应用。已有旧连接时，确认选的是当前 ID 对应的应用。
4. 回到向导点击“复制验证提示词”，发到刚才的对话。向导会自动确认结果，无需点刷新。
5. 显示“连接已验证”后，点击“复制项目提问模板”，发到 ChatGPT 开始使用。

如果看不到 Tunnel 或创建入口，核对开发者模式权限、当前 ChatGPT 工作区关联及 Tunnels Use 权限。暂不具备条件时可先使用本机功能，或采用已有 HTTPS 与 GitHub OAuth App 的高级公网方式。

**本机检查通过不代表 ChatGPT 已接通。** 真实验证只来自发到 ChatGPT 的限时 `verify_connection` 调用；提示词过期可重新复制。历史成功时间也不代表此刻仍在线。

## 日常操作

- 保持本机服务和 VS Code 扩展运行；私有隧道随扩展启动、恢复和关闭。手动停止后不会自动重启。
- 文本使用 `read_file`，UTF-8 CSV / XLSX 使用 `read_table`；PDF、图片和旧版 XLS 暂不解析，表格不执行公式。
- 允许修改时，在首页分别开启“允许提出修改”和“允许本机应用”，在 VS Code 查看差异并明确应用。应用后运行项目自己的测试。
- 已配置旧公网 OAuth 时，保存私有设置会暂停原公网方式并保留配置，可从首页“恢复原公网连接”。ChatGPT 中的应用需分别管理。
- 需要检查或升级时，在首页使用“检查连接”“导出脱敏诊断包”“检查并安装附带版本”和“回退上一备份”。开机启动项只启动本机服务，独立后台隧道助手尚未实现。

## 清除旧授权，重新开始

1. 首页“检查与修复”点击 **恢复初始状态**，检查清理范围后确认一次。
2. 等待 **已恢复初始状态**。中途失败或重启，回到首页点击 **继续恢复初始状态**。
3. 源码、业务文件和修改历史会保留。点击 **选择文件夹**，重新授权，再连接 ChatGPT。
4. 使用过网页连接时，按完成页提示在 ChatGPT、GitHub 或 OpenAI Platform 处理旧连接；本机清理不会撤销外部账号授权。

如果提示当前服务不支持安全重置，先点击 **检查并安装附带版本** 再重试。正在配置连接、应用修改、恢复或升级时，先完成或取消该操作。详细范围见 [恢复说明](../extensions/vscode/RESET.md)。
