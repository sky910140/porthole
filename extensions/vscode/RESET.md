# 恢复初始状态

需要重新开始配置、清除之前的本机授权时，使用首页的“恢复初始状态”。不用打开终端，也不用手动删除目录。

## 操作

1. 安装完整的 0.8.0 VSIX，按提示重新加载 VS Code。
2. 按 `Ctrl+Shift+P`，运行 **舷窗: 打开首页**。
3. 在“检查与修复”中点击 **恢复初始状态**，阅读清理范围，确认一次。
4. 等待“已恢复初始状态”。点击 **选择文件夹**，重新授权需要的项目，再连接 ChatGPT。

也可以从命令面板直接运行 **舷窗: 恢复初始状态**。

| 自动清除 | 保留 |
|---|---|
| 本机所有项目授权、编辑器绑定、同步和连接草稿 | 安装的运行包和扩展版本 |
| 本机保存的 OAuth 客户端凭据和 Tunnel 运行密钥 | 源码、业务文件和文件夹 |
| 配对码、网页授权状态和验证记录；旧本机令牌失效 | 修改历史、加密内容和恢复备份 |
| 停止本安装的服务和扩展拥有的隧道，关闭本安装开机启动 | 其他程序、其他安装的启动项和凭据 |

如果当前旧服务不支持安全重置，先点击首页 **检查并安装附带版本**，完成升级后再重置。重置按钮不会自动替换运行包。

正在应用修改、撤销、恢复文件或升级时，先完成对应操作。程序会在清理前检查，阻止这些操作与重置同时执行。

## 中途失败或重启

重新打开首页，点击 **继续恢复初始状态**。程序会检查已完成的步骤并继续；重试不会重复授权，也不需要再次确认同一次恢复。

系统凭据无法访问、状态文件无法读取等问题会显示对应提示。不要手工删除恢复标记，也不要用旧升级备份恢复已撤销的授权。旧备份跨越恢复记录时，程序会拒绝回退。

## 外部账号需自行处理

本机恢复完成不代表外部账号中的连接已删除。完成页会列出相应入口，点击打开页面也不会自动标记为已撤销。

- **ChatGPT**：打开插件管理，找到旧 Porthole 连接，断开或移除。需要时重新添加一条当前连接。
- **GitHub**（使用过公网 OAuth）：在 [应用授权](https://github.com/settings/applications) 中撤销 Porthole 对本人账号的访问；这与删除自己创建的 OAuth App 是不同操作。
- **OpenAI Platform**（使用过私有 Tunnel）：在 [Tunnels](https://platform.openai.com/settings/organization/tunnels) 检查旧 Tunnel；不再使用时由本人删除。在 [API Keys](https://platform.openai.com/api-keys) 撤销专用于旧连接且不再需要的运行密钥。共用密钥应先确认其他用途。

这些页面需要本人登录；工具不会读取账号密码或代为删除云端资源。
